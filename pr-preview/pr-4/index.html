About

つくることと、支えること

バックエンドとインフラを主な領域とするエンジニアです。 アプリケーションコードだけでなく、その下で動くネットワークやコンテナ基盤まで触れることで、 障害の原因を一箇所に閉じ込めずに追えるようにしています。

最近は Go / gRPC を用いたサーバー実装と、Kubernetes を用いた自宅ラボの構成管理を中心に手を動かしています。 手元で一度ぜんぶ組み立ててみることが、いちばん理解が早いと思っています。

  • Main Stack Go, gRPC, Kubernetes
  • Interest 分散システム, IaC, 可観測性
  • Location Japan
